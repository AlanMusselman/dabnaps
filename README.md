# Dabnaps LLC — Storefront, In-House Silicone Lab & Inventory Command Center

*"Where Concentrates Culture Meets Cloud-Nine Comfort."*

## Key Files & Directories
- [`index.html`](./index.html) & [`assets/app.js`](./assets/app.js) — Single-Page E-Commerce Storefront, In-House Silicone Lab showcase, and Inventory/Admin Portal.
- [`BRAND_AND_OPERATIONS.md`](./BRAND_AND_OPERATIONS.md) — Brand identity guidelines, color palette (`#FFD23F` Radiant Dab Gold / `#0A0A0A` Obsidian), and 5-step platinum-cured silicone manufacturing SOP.
- [`data/inventory.json`](./data/inventory.json) & [`data/inventory-sync.js`](./data/inventory-sync.js) — Live SKU catalog, stock counts, reorder thresholds, and in-house curing batch tracker.
- [`scripts/manage-inventory.ps1`](./scripts/manage-inventory.ps1) — CLI utility for stock adjustments, price updates, and batch restocking.
- [`scripts/deploy-godaddy.ps1`](./scripts/deploy-godaddy.ps1) & [`api.php`](./api.php) — GoDaddy hosting sync and backend persistence endpoint.
